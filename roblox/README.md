# Coin Rush

Collect coins in an arena, grab blue pads for a speed boost. Coins persist via DataStore.

## Run
1. Install [Rojo](https://rojo.space) and the Rojo Studio plugin.
2. `rojo serve` in this folder, then click Connect in Studio.
3. Press Play. (Enable *Game Settings > Security > Enable Studio Access to API Services* to test saving.)

Tweak gameplay in `src/shared/Config.luau`.
